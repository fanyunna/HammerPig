# 敲小猪 · 本周卡片扩展

以团队 P1 分支提交 `4489ceb` 为基线，在已合入的卡片系统 2.0 上新增六张卡。通过原有三选一抽取，按 C 查看，重开清除本局状态。

| 卡片 | 类型 | 效果 |
|---|---|---|
| 酒馆赊账 | 代价 | 即时 +¥45，本局挥锤冷却 +15% |
| 破罐保险 | 代价 | 敲猪正收益 ×0.9，每累计 3 次空挥返还 2 体力，按队友的空挥额外扣体力规则结算后再返，不超过上限 |
| 校准锤 | 进化 | 空挥后准备一次蓄力，下次命中消耗。Lv1 +1 伤害，Lv2 +2，Lv3 另回 2 体力，Lv4 伤害增至 +3 |
| 赶路马刺 | 进化 | 连击仍有效且已达到 3 连击时，下一锤冷却按等级缩短 10% / 15% / 20% / 25% |
| 收据收藏家 | 任务 | 持有后累计还清 1 / 3 / 5 张账单升到 Lv2 / Lv3 / Lv4。返现分别为 ¥2 / ¥4 / ¥6，触发升级的还账按新等级返现。考核奖励自动清掉一张账单也计入 |
| 稳手学徒 | 任务 | 持有后完成 2 / 4 / 6 组五连击升级。每段连续连击只在第 5 次有效命中时记一次，挥锤体力消耗累计减 0.25 / 0.5 / 0.75 |

代价卡和任务卡每局只能选一次，进化卡可以重复选择直至 Lv4。两张新任务满级后停止累加进度。C 面板改为双列容纳新增卡。整体冷却和体力沿用已有下限。

实现主要在 `scripts/card_build.gd`，玩法入口在 `scripts/main.gd`。验证覆盖真实选卡、空挥及命中、返现及支付失败、持续连击、卡池排除和重置。

在 Godot 4.6.3 Linux headless 上，原冒烟测试 165 项、原卡片测试 490 项、新增卡片测试 29 项均通过，三条命令退出码均为 0。启动时的部分图片导出提示及退出时的资源清理提示仍存在。Windows 导出、画面和实际数值手感待验证。
