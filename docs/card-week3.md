# 施晨煜 · 本周卡片扩展

开发基线为团队 P1 的 d216efc（上周六卡 PR #4 已合入）。

| 卡片 | 类型 | 规则 |
|---|---|---|
| 长柄重锤 | 代价 | 命中范围倍率加 0.2，挥锤冷却乘 1.1，每局一次 |
| 节俭握把 | 代价 | 每锤省 0.5 体力，敲猪正收益乘 0.9，每局一次 |
| 碎瓷回收 | 进化 | 取得后每三次直接击碎正收益普通猪，额外奖励 2/4/6/8 金币，对应 Lv1–4 |
| 破罐工匠 | 任务 | 取得后直接击碎正收益普通猪累计 4/8/12 只自动升至 Lv2/3/4，冷却依次减 3%/6%/9% |

“普通击碎”包含金猪等正常猪种，排除转盘专属金猪、负收益猪以及爆破/连锁的次级击碎。碎瓷奖励沿用正常击碎双倍收益结算。升级碎瓷不清空已累计的两次击碎进度。重复选代价卡和满级进化卡不会再生效。重开清除全部本局状态。沿用现有卡池、三选一、自绘卡面和 C 构筑面板。

修改仅在 scripts/card_build.gd 与 scripts/main.gd 接入新效果，新增 tests/card_week3.gd。

实际验证环境为 Linux Godot 4.7.2。原冒烟 165 项、原卡片 490 项、上周扩展 33 项、本周新增 45 项检查通过，退出码均为0。图片资源导出警告、退出时资源清理提示仍存在。Windows导出、Mac人工画面、实际数值手感未验证。本周远程推送和PR创建由本机提交脚本及用户完成。

复测命令：
`godot --headless --editor --import`
`godot --headless --script res://tests/card_week3.gd`
