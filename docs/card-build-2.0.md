# 升级卡片系统 2.0 交接 · 施晨煜

## 基线与范围

基于用户从 `feature/card-upgrade-p1`、P1 提交 `25dce11` 导出的 ZIP。ZIP 不含 Git 历史；交付仓库中的 baseline 提交仅用于生成差异，不冒充原提交。保留队友的场景、美术、音效、Windows 导出设置、账单与 Meta 系统。团队采用每周协同开发，不记录其他成员未经确认的分工。

任务从取得卡片后计数，目标为累计值，不是每级重新计数。Lv4后的100只/5张为最终任务奖励，不存在Lv5。伤害、范围等前级效果保留。代价卡不重复，进化满级不再进入卡池，任务卡取得后不再进入卡池。原有其他卡保持原逻辑；重锤改造由原来的无限叠加改为四级进化。

当前 P1 没有概率暴击结算，只有名为 crit 的音效；本次在直接锤击中新增一次暴击判定，次级伤害不再暴击。连锁与爆破共用预算与已访问集合，不能相互递归发钱。次级奖励不会让催债猪的负收益变成正收益。

## 协同

- 过载+狂战士Lv4+轻柄：狂暴额外体力消耗×0.5。
- 贪婪收益倍率>1+贪婪税+债务操盘手：成功还款额外¥5。
- 重锤+连锁+范围倍率>1.1：次级击碎额外¥3。普通满级次级奖励¥5只给一次，不因同时拥有两张满级卡而重复。

## 接入点

- `scripts/card_build.gd`：所有新增卡定义、等级、任务计数、计时、连锁、HUD。数值目前集中在此模块，未迁入 JSON。
- `scripts/main.gd`：抽卡池接入、选卡、重置、直接攻击暴击、共享击碎结算、成功还款事件、游戏计时接入。
- `tests/card_build.gd`：新增独立测试，原 `tests/smoke.gd` 未删除或改写。
- `C`：打开本局构筑与任务进度，暂停游戏；再按C返回。按R仍可重开。卡片描述支持多行。
- 新账单沿用 bills/sort_bills/pay_bill，不增加第二套债务状态。
- 重开清除所有卡片和计数、计时、特效；原Meta进度不清除。
